# Tonal Spot Design System

## Brand & Style
The design system adopts a **Tonal Spot** style, blending calm organic tones with polished corporate reliability. It evokes a sense of grounded stability, quiet confidence, and thoughtful craftsmanship.

## Colors
- **Primary**: `#4a7c59` (Forest Sage)
- **Secondary**: `#6b6358` (Warm Taupe)
- **Tertiary**: `#c4a66a` (Muted Gold)
- **Neutral**: `#4a4e4a` (Deep Organic Gray)

## Typography
- **Headlines**: Literata
- **Body & Labels**: Nunito Sans

## Layout & Spacing
Built on a fluid grid system utilizing consistent spacing tokens (`space-xs` through `space-xl`) with generous padding and clear alignment.

## Elevation & Depth
Utilizes tonal layering and soft ambient shadows to establish clear visual hierarchy.

## Shapes
Rounded aesthetic (`roundedness: 2`), featuring 0.5rem base corner radii for interactive elements and containers.

## Components
Styled consistently with rounded corners, organic color fills, and clear interactive states for buttons, inputs, cards, and navigation elements.
